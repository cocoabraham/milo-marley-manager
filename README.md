# Milo + Marley
### Small Business Management Platform

A modular business management application designed to help small businesses simplify daily operations, manage sales and expenses, organize products, and gain better visibility into business performance.

Built with **Next.js, React, TypeScript, and Material UI**.

> 🚧 **Project Status:** Active Development
>
> This project is continuously evolving. Current functionality focuses on business operations, with additional features planned for future releases.

---

## 🎯 Project Overview

Milo + Marley began as a practical solution to the operational challenges of managing a small pet products business.

Like many small businesses, Milo + Marley needed a centralized system to organize sales, expenses, products, and financial information without relying on disconnected spreadsheets and manual processes.

The initial objective was to create an intuitive application that simplifies everyday business operations.

As development progressed, the project evolved into a broader product concept: a modular business management platform adaptable to different types of small businesses.

Potential applications include retail businesses, pet product companies, and service providers such as mobile pet grooming businesses.

---

## 💡 The Business Problem

Small businesses often operate with limited resources and rely on manual processes to manage their activities.

Common challenges include:

- Fragmented business information
- Manual sales and expense tracking
- Limited visibility into financial performance
- Difficulty managing product information
- Inconsistent business workflows
- Lack of centralized reporting

These challenges can lead to operational inefficiencies and make it harder for business owners to make informed decisions.

### The Opportunity

Design a lightweight, accessible business management application that consolidates essential operations into a unified interface.

The solution should prioritize usability, operational efficiency, and adaptability.

## 🏗️ Application Architecture

The application uses Next.js App Router and a modular front-end structure.

```text
src/
├── app/
│   ├── expenses/
│   ├── products/
│   ├── reports/
│   ├── sales/
│   ├── settings/
│   ├── users/
│   ├── layout.tsx
│   └── page.tsx
│
├── components/
│   └── AppShell.tsx
│
├── context/
│   ├── BusinessSettingsContext.tsx
│   ├── PaymentMethodsContext.tsx
│   └── ProductsContext.tsx
│
└── theme/
    └── theme.ts
```

The structure separates application routes, reusable components, shared state, and visual configuration.

This approach supports maintainability and future expansion.

## 🎨 UX/UI Design Principles

The interface is designed around several core principles.

**Clarity**

Present information in an understandable and organized way.

**Consistency**

Maintain predictable interaction patterns and reusable interface components.

**Efficiency**

Reduce unnecessary steps when performing common business operations.

**Scalability**

Design workflows and components that can support additional business requirements.

**Accessibility**

Consider usability, readability, and accessible interaction patterns throughout development.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/cocoabraham/milo-marley-manager.git
```

Navigate to the project directory:

```bash
cd milo-marley-manager
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

http://localhost:3000
